
### Client repos

- **Untraceable test.** A test for a spec'd behaviour that doesn't name its `AC-<spec>-<n>` id.
- **Deliverable not updated.** An infra, CI or data-model change where the matching file in `docs/deliverables/` (infrastructure, CI/CD or data) exists but wasn't updated, and the PR doesn't say why.
- **Personal data.** A new field or log line holding personal data (name, email, phone, address, IBAN, BSN) without a note in the PR for the data deliverable.
- **Unapproved scope.** Behaviour from a `change-request` that has no Client approval link.
